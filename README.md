# Klasifikasi Kualitas Udara DKI Jakarta Berdasarkan Data Sensor Polutan Menggunakan Algoritma Machine Learning

Perbandingan algoritma machine learning (KNN, SVM, Random Forest) untuk klasifikasi kualitas udara di DKI Jakarta berdasarkan data sensor polutan.

---

## Tujuan Penelitian

Membandingkan performa tiga algoritma klasifikasi machine learning dalam memprediksi kategori kualitas udara DKI Jakarta menggunakan data sensor polutan (PM25, PM10, SO2, CO, O3, NO2).
